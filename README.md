# ecommerce-be-fe

## Code Quality Tools

Before pushing your code, ensure code quality by running the following commands:

### Linting
```bash
npm run lint
```
This will check your code for potential errors and enforce consistent coding style.

### Code Formatting
```bash
npm run prettier
```
This will automatically format your code according to the project's Prettier configuration.

### Pre-push Checklist
1. Run linting check
2. Run code formatting
3. Fix any issues reported by the tools
4. Commit and push your changes
